## 介绍

_Touhou Pet时一个在安卓平台的悬浮窗桌宠, 使用Kotlin语言编写

项目当前仍处于Alhpa阶段, 尚不提供构建产物

> 本项目前身为[Baka Pet](https://github.com/9halfcirno/baka-pet),
> 使用Kotlin完全进行了重写, 放弃使用QuickJs-Android类库, 而是使用QuickJs-kt

- 支持自定义帧动画
- 使用JS脚本驱动桌宠的行为, 如移动/切换动画/存储数据等

## Future
